# Portfólio — Aron Benedito Paulo Dias

Website com estilo editorial de caderno de design: papel claro, tipografia serifada, verde escuro e laranja. Construído com HTML, CSS e JavaScript.

## Projectos
- **Estúdio de Ideias** — cria um plano inicial de três passos para uma ideia.
- **Modo Foco** — temporizador de concentração com durações de 25, 15 e 5 minutos, pausa e reinício.
- **Memória em Jogo** — jogo de cartas para encontrar seis pares e contar jogadas.

## Abrir
Extrai o ZIP, abre a pasta no VS Code e inicia `index.html` com Live Server (ou abre directamente no navegador).

## GitHub Pages
Cria um repositório público, envia o conteúdo desta pasta para a raiz (não o ZIP) e em Settings → Pages selecciona Deploy from a branch, `main` e `/(root)`.

Antes de publicar, substitui `email@exemplo.com` por um contacto que Aron queira divulgar ou remove o link. Confirma que ele concorda com a publicação do nome completo.
